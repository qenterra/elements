# Feature Overview

## Pick precisely

- Hover to preview and click to lock an element.
- Move through parent and child layers without silently retargeting the active
  breadcrumb.
- Use keyboard controls or the responsive picker, which becomes a touch-sized
  bottom sheet in narrow viewports.

## Change what you see

- Hide elements.
- Replace visible text while preserving the original DOM nodes and listeners.
- Round corners, blur, dim, or desaturate a target.
- Add custom CSS after sanitization.
- Undo and redo rule changes.

## Manage saved rules

- Store rules per site in browser-managed extension storage.
- Pause rules without deleting them.
- Search, sort, edit, and remove rules in Options.
- Export and import a validated JSON backup with transactional rollback.
- Keep private-window changes temporary.

## Themes and onboarding

Elements supports Light, Dark, and System themes across the picker, Options,
and onboarding. The first-run guide explains activation, selection, actions,
saved rules, and privacy boundaries.
