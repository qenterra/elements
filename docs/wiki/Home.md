# Elements

Elements is a Manifest V3 browser extension for hiding distractions, editing
visible text, and restyling page elements. Saved rules stay in browser-managed
extension storage and can be reapplied when a matching site is opened again.

## Product status

Elements 1.0.0 is available as an unsigned Chrome and Chromium release archive.
Installation from GitHub uses Developer mode. Chrome Web Store distribution
still requires its review and signing process.
